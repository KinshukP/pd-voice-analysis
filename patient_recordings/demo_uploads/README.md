# Direct Upload Demo WAVs

These are real WAV recordings made for this project, copied from `recordings/`. They are not Parkinson's patient recordings and must not be presented as clinical patient evidence.

## Demo use

With the backend running in explicitly labelled demo mode (`PDVOICE_DEMO=1`), upload all five files through the website. Because every file has source `uploaded`, the demo script produces the positive presentation path and marks the response:

`DEMO MODE — SIMULATED RESULT`

The result is scripted from how the files were supplied, not inferred from their audio.

## Website

Open `http://127.0.0.1:5173/`, choose a gender, choose **upload audio files**, select all five WAVs, and analyse them.
